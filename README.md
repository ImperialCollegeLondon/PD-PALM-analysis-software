Biomed filtering python script and java based PD-interpreter. Used to filter PD-PALM localizations and carry out neighborhood analysis to determine clustering. In Biomed programme the parameters you can alter are:
diff and length. Where diff is the search radius for filtering and length is the number of frames. eg diff=0.15 and length=10 would be removing localisations which occured within 15 nm and 10 frames. 
When running the scripts, the Biomed.jar and Biomed.bat and your data file should be in the same folder

Input your filtered localisations into the PD_interpreter. You can alter the search radius for the neighbourhood analysis.
